MODULO DE REGISTRO DE PACIENTES — HealthApp



Objetivo:

Definir el flujo inicial para registrar pacientes.



Datos requeridos:

\- Nombre completo.

\- Fecha de nacimiento.

\- Correo electronico.

\- Telefono de contacto.



Flujo propuesto:

1\. El usuario introduce sus datos.

2\. El sistema verifica los campos obligatorios.

3\. El sistema valida el formato de los datos.

4\. Se solicita confirmar el registro.

5\. El sistema informa el resultado.



Consideracion:

Los datos personales deben protegerse y manejarse

conforme a las medidas de seguridad aplicables.
